# Jump Caption Starter

このフォルダは、Codexで開発を開始するための設計パッケージです。

## 開始手順

1. このフォルダを `Documents/Projects/jump-caption` などへ置く
2. Codexでフォルダを開く
3. `CODEX_FIRST_PROMPT.md` の内容をCodexへ渡す
4. Sprint 0のみ実装させる
5. 実装結果を確認してから次のSprintへ進む

## 文書の役割

- `PROJECT.md`: プロジェクト全体の目的と仕様
- `DECISIONS.md`: 固定した設計判断
- `NEXT.md`: Sprint計画
- `CODEX_FIRST_PROMPT.md`: Codexへの最初の実装指示
