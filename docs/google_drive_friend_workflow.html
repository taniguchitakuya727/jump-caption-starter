Googleドライブで字幕修正を依頼する手順

あなたがJump Captionで書き起こしを作り、友人はGoogleドライブ上の音声/動画とSRTを使って字幕を修正します。 友人のPCにはPython、FFmpeg、Whisperは不要です。

あなたが準備するもの

  1. Jump Captionで動画から書き起こしを作る
  2. outputs/ から音声/動画ファイルとSRTを取り出す
  3. Googleドライブにフォルダを作る
  4. 音声/動画ファイルとSRTをアップロードする
  5. そのフォルダを友人に共有する
例:
sample_cut.mp4
sample_cut.srt

友人がやること

  1. Googleドライブから音声/動画ファイルとSRTをダウンロードする
  2. オンライン字幕エディタ を開く
  3. 音声/動画ファイルを選ぶ
  4. SRTを選ぶ
  5. 再生しながら字幕を修正する
  6. SRTを書き出し を押す
  7. 修正版SRTをGoogleドライブにアップロードする

重要

オンライン字幕エディタはブラウザ内だけで動きます。音声/動画やSRTはエディタのサーバーへアップロードされません。 Googleドライブから友人のPCに一度ダウンロードして、ブラウザで読み込む方式です。

Googleドライブ上のSRTを直接上書き保存する機能はまだありません。修正後はSRTを書き出して、Googleドライブに戻してください。
