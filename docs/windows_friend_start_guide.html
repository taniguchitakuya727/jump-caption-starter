Windows用

Jump Caption
かんたん開始ガイド

明日、友達のWindows PCで試すための手順です。基本はこれだけです。

start_windows.bat をダブルクリック

まず渡すもの

友達には、次のフォルダをまるごと渡します。

jump-caption-mvp

おすすめの置き場所:

C:\JumpCaption

このフォルダの中に start_windows.bat、 start_windows_core.bat、 install_ffmpeg_windows.bat、app、 pyproject.toml、tools が入っていればOKです。

友達のPCで最初にやること

フォルダを開く

jump-caption-mvp フォルダを開きます。

起動する

start_windows.bat をダブルクリックします。

黒い画面を待つ

Python、FFmpeg、必要なパッケージを確認します。閉じずに待ちます。

エラーが出ても黒い画面は閉じないので、表示された日本語メッセージを確認します。

ブラウザが開いたら準備完了

開くURLは http://127.0.0.1:8000 です。

Pythonがないと言われたら

  1. 画面に出るPython公式ページを開く
  2. Python 3.10 または 3.11 を入れる
  3. Add python.exe to PATH にチェックする
  4. もう一度 start_windows.bat をダブルクリック

Python 3.13だけが入っているPCでは、字幕生成で止まることがあります。 この配布版ではPython 3.10 / 3.11を使います。

FFmpegがないと言われたら

画面にこう出たら:

FFmpegを自動インストールしますか？ [Y/Enter]:

まずは Y を入力して Enter。終わったら、もう一度 start_windows.bat をダブルクリックします。

初回だけ時間がかかります

  • 仮想環境 .venv の作成
  • Pythonパッケージのインストール
  • 初めて字幕生成するときのWhisperモデルダウンロード

黒い画面に文字が流れている間は、閉じずに待ってください。

Jump Captionの使い方

動画を選ぶ

短めの動画から試します。最初は30秒から1分くらいがおすすめです。

ジャンプカット

ジャンプカット を押して、無音をカットします。

字幕生成

字幕生成 を押して、Whisperで字幕を作ります。

読みやすく整形

字幕を読みやすく整形 を押します。

直して保存

必要なら手で字幕を直して、保存 を押します。

出力ファイル

処理結果は outputs フォルダに入ります。

  • _cut.mp4: CapCutに入れる動画
  • .srt: 字幕ファイル
  • .txt: 文字起こしテキスト
  • _subtitles.json: 再編集用データ

2回目以降

また start_windows.bat をダブルクリックするだけです。 初回に作った環境を使うので、通常は初回より早く起動します。

Existing .venv uses unsupported Python と出たら、 Python 3.11を入れたあと C:\JumpCaption\.venv を削除して、 もう一度起動します。

終了するときは黒い画面を閉じます。ブラウザだけ閉じても、黒い画面が残っている間は動いています。

困ったとき

  • 黒い画面に出ている日本語メッセージを見る
  • ブラウザのURLが http://127.0.0.1:8000 か確認する
  • outputs フォルダにファイルができているか見る
  • インターネットにつながっているか確認する
  • セキュリティソフトが止めていないか確認する

最初は、音声入りの短い動画で試してください。

sample.mp4

長い動画や日本語ファイル名は、最初の動作確認が終わってから試すと安心です。
