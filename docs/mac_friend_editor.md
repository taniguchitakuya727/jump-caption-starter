# Macを使って友人に字幕修正だけしてもらう手順

この方法では、あなたのMacでJump Captionを起動します。
友人は同じWi-Fiからブラウザでアクセスし、生成済み字幕を修正します。

友人のPCやiPadには、Python、FFmpeg、Whisperは不要です。

## 事前にあなたがやること

1. あなたのMacで通常どおり動画を処理する
2. ジャンプカットする
3. 字幕生成する
4. `outputs/` に次のようなファイルができていることを確認する

```text
xxx_cut.mp4
xxx_cut.srt
xxx_cut.txt
xxx_cut_subtitles.json
```

友人が編集するのは、この `_subtitles.json` です。

## 友人用エディタを起動する

Macのターミナルで、プロジェクトフォルダに移動して次を実行します。

```bash
./start_mac_friend_editor.sh
```

初回はPythonパッケージ確認のため少し時間がかかります。

起動すると、ターミナルに次のようなURLが出ます。

```text
Friend URL on the same Wi-Fi:
  http://192.168.x.x:8000
```

このURLを友人に送ってください。

## 友人ができること

- 字幕一覧からエディタを開く
- 動画を見ながら字幕を修正する
- 開始時刻、終了時刻、本文を直す
- 検索置換する
- Undo / Redoする
- 保存する
- 自動保存される

## 友人用モードで隠れる機能

- 動画アップロード
- ジャンプカット
- Whisper字幕生成
- 字幕の追加、削除、分割、結合
- 字幕の自動整形

友人には、書き起こし済み字幕の修正だけをしてもらう想定です。

## 止める方法

あなたのMacのターミナルで `Control-C` を押します。

## うまく開けない場合

- あなたのMacと友人の端末が同じWi-Fiにいるか確認する
- MacのファイアウォールでPythonの通信が許可されているか確認する
- ターミナルに出た `http://192.168.x.x:8000` のURLを正確に送る
- Macがスリープしないようにする

## 注意

この方法は同じWi-Fi内での共有向けです。
インターネット全体に公開する用途ではありません。
