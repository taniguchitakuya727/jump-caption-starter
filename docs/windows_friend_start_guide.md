# Jump Caption Windowsかんたん開始ガイド

明日、友達のWindows PCで試すための手順です。  
基本は **`start_windows.bat` をダブルクリックするだけ** です。

## まず渡すもの

友達には、次のフォルダをまるごと渡します。

```text
jump-caption-mvp
```

このフォルダの中に、次のファイルが入っていることを確認してください。

- `start_windows.bat`
- `start_windows_core.bat`
- `install_ffmpeg_windows.bat`
- `README_WINDOWS.md`
- `app`
- `pyproject.toml`
- `tools`

おすすめの置き場所:

```text
C:\JumpCaption
```

デスクトップやダウンロードフォルダでも動く可能性はありますが、最初は短くて分かりやすい場所がおすすめです。

## 友達のPCで最初にやること

1. `jump-caption-mvp` フォルダを開く
2. `start_windows.bat` をダブルクリックする
3. 黒い画面が出るので閉じずに待つ
4. ブラウザが開いたら準備完了

`start_windows.bat` は、エラーが出ても黒い画面が閉じないようにしてあります。止まった場合は、画面に出ている日本語メッセージを確認してください。

開くURL:

```text
http://127.0.0.1:8000
```

## Pythonが入っていないと言われたら

`start_windows.bat` が自動で確認します。  
Pythonがない場合は、日本語で案内が出て、Python公式ページが開きます。

やること:

1. Python 3.10 または 3.11 をインストールする
2. インストール画面で **Add python.exe to PATH** にチェックを入れる
3. インストール後、もう一度 `start_windows.bat` をダブルクリックする

Python 3.13 だけが入っているPCでは、字幕生成で止まることがあります。この配布版では Python 3.10 / 3.11 を使います。

もし黒い画面に `Existing .venv uses unsupported Python` と出たら、古い `.venv` が Python 3.13 で作られています。Python 3.11 を入れたあと、`C:\JumpCaption\.venv` フォルダを削除して、もう一度 `start_windows.bat` をダブルクリックしてください。

## FFmpegが入っていないと言われたら

`start_windows.bat` が自動で確認します。  
FFmpegがない場合は、日本語で案内が出ます。

画面に次のように出たら:

```text
FFmpegを自動インストールしますか？ [Y/Enter]:
```

まずは `Y` を入力して Enter を押してください。  
自動インストールが終わったら、もう一度 `start_windows.bat` をダブルクリックします。

うまく入らない場合は、画面に出るFFmpegのページを開いて手動インストールします。

## 初回起動で時間がかかるところ

初回だけ、次の処理に時間がかかります。

- 仮想環境 `.venv` の作成
- Pythonパッケージのインストール
- 初めて字幕生成するときのWhisperモデルダウンロード

黒い画面に文字が流れている間は、閉じずに待ってください。

## Jump Captionの使い方

1. 動画ファイルを選ぶ
2. `ジャンプカット` を押す
3. カット済み動画ができる
4. `字幕生成` を押す
5. 字幕エディタが開く
6. `字幕を読みやすく整形` を押す
7. 必要なら字幕を手で直す
8. `保存` を押す

## 出力されるファイル

処理結果は、フォルダ内の `outputs` に入ります。

- `_cut.mp4`: CapCutに入れる動画
- `.srt`: 字幕ファイル
- `.txt`: 文字起こしテキスト
- `_subtitles.json`: Jump Captionで再編集するための保存データ

## 2回目以降

次からは、また `start_windows.bat` をダブルクリックするだけです。

初回に作った環境を使うので、通常は初回より早く起動します。

## 終了するとき

黒い画面を閉じると、Jump Captionも終了します。  
ブラウザだけ閉じても、黒い画面が残っている間はサーバーが動いています。

## 困ったとき

まず見るところ:

- 黒い画面に出ている日本語メッセージ
- `outputs` フォルダにファイルができているか
- ブラウザのURLが `http://127.0.0.1:8000` になっているか

よくある原因:

- Pythonが入っていない
- Pythonインストール時に `Add python.exe to PATH` にチェックしていない
- Python 3.13 だけが入っている
- `.venv` が Python 3.13 で作られている
- FFmpegが入っていない
- インターネットにつながっていない
- セキュリティソフトが止めている

## 明日のおすすめチェック

最初は短い動画で試してください。

- 30秒から1分くらい
- 音声が入っている動画
- ファイル名は英数字がおすすめ

例:

```text
sample.mp4
```

長い動画や日本語ファイル名は、動作確認が終わってから試すと安心です。
